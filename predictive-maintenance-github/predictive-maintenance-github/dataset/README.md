# Dataset

Download the **AI4I 2020 Predictive Maintenance Dataset** from the UCI Machine Learning Repository:

https://archive.ics.uci.edu/dataset/601/ai4i+2020+predictive+maintenance+dataset

Place the downloaded CSV in this folder and rename it to:

`ai4i2020.csv`

The dataset is not included in this repository. Check the dataset's license/terms on the UCI page before redistribution.
